What it checks

    
Hooks (settings.json)

    
    
      
  • Event names are checked against the full documented list (PreToolUse, PostToolUse, Stop, and 26 others); an unrecognized name is usually a typo.
    • 
      
  • Each matcher group needs a nested hooks array. A flat shape with command directly on the matcher group, or a matcher given as an object instead of a string, is exactly the contradiction reported in issue #31187.
    • 
      
  • A matcher-less entry on Stop or Notification is schema-valid but matches a shape reported as silently failing to load in issue #11544.
    • 
      
  • Every hook handler needs a type (command, http, mcp_tool, prompt, or agent) and the fields that type requires (for example command for type "command").
    • 
      
  • timeout must be a number of seconds, not a quoted string.
    • 
      
  • Common nested-field typos: matcher placed on the handler instead of the group, Command/Type instead of lowercase, timeoutMs instead of timeout.
    • 
    


    
Agent / SKILL.md frontmatter

    
    
      
  • Agent files require name and description. A missing name on an otherwise well-formatted file is the exact bug in issue #6377. SKILL.md files do not require name (it defaults to the directory name); description is recommended, not required.
    • 
      
  • name must be a lowercase, hyphenated slug. A malformed name is a common reason custom agents are not discovered, as reported in issue #20931.
    • 
      
  • tools / allowed-tools should be a comma-separated string or a YAML list.
    • 
      
  • model is checked against opus, sonnet, haiku, inherit, or a full model id.
    • 
      
  • Fields outside this tool's known list get a soft warning, not a hard error, because Claude Code's own SKILL.md validator has shipped a bug rejecting valid extended fields it did not yet recognize (issue #25380).
    • 
      
  • The frontmatter parser is hand-written and covers the subset Claude Code frontmatter actually uses (key: value scalars, quoted strings, inline and block lists). It is not a general YAML parser; see the README for exactly what is and is not supported.
    • 
    


    
Everything on this page runs in your browser. Nothing you paste is uploaded, stored, or sent anywhere.
